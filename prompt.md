# ADAPTIVE FASHION PROTOTYPE - TEAM KALVIBERS

## OVERVIEW
Build a working interactive web application for Track 5: Fashion for People.
Team Members: M. Venkata Durga Lakshmi, M. Lakshmi Pavani, Godasu Sai Vardhan, Y. Divya Sri.

## TECH STACK
- Framework: React (Vite) + Tailwind CSS + Lucide Icons
- Layout: Modern accessibility design with High-Contrast Mode toggle and Large Touch Targets (WCAG compliant)

## 4 MAIN SCREENS / PROTOTYPE FLOWS TO BUILD:

1. ACCESSIBILITY PROFILE BUILDER (Step 1)
   - Questionnaire inputs:
     * Mobility Type (Wheelchair/Seated, Crutches, Bed-bound)
     * Dexterity Needs (Fine motor difficulty, Hand strength limitations)
     * Preferred Fasteners (Magnetic snaps, Side zippers, Velcro, Elastic waist)
     * Sensory Needs (Tagless, Flat seams)

2. AI GARMENT SCANNER & ANALYZER (Step 2)
   - File Upload zone for clothing image.
   - Simulation engine that analyzes the photo and tags accessible features:
     * Displays a "Functional Accessibility Match Score" (e.g., 94% Match).
     * Visual badges showing detected features: "Magnetic Closure", "Easy-Pull Zipper", "Flat Seams".

3. ACCESSIBLE CLOTHING CATALOG & FILTERS (Step 3)
   - Interactive grid showing adaptive clothing items.
   - Ability to filter by: "Seated Cut", "Magnetic Shirts", "Easy-Open Pants".
   - Each card displays functional features instead of just size.

4. GARMENT CUSTOMIZATION & TAILOR REQUEST (Step 4)
   - Modal/Page for requesting specific modifications:
     * "Replace buttons with magnetic snaps"
     * "Add side-seam zipper"
     * "Remove neck tags & flatten inner seams"
   - Live cost calculator and submit button with instant success feedback.
